## Локальная версия

Из корня: `python -m http.server 8788`, затем http://localhost:8788/ . tools/rebalance.py строит план, tools/curation.py хранит подборку, tools/tides.py — приливы. tools/export-maps.html?day=1 экспортирует карты (дни 1–7, overview — обзор); tools/build_pdf.py создаёт PDF, tools/verify.py проверяет маршрут.

Сайт и PDF показывают один основной план. Перестановки выбранных ресторанов в браузере проверяют два дня, покрытие выбранных заведений и сон; PDF не меняется автоматически. Полный каталог из 67 заведений доступен для выбора альтернатив, он не является обязательным маршрутом.
