## Локальный запуск

Из корня: `python -m http.server 8788`, затем http://localhost:8788/ . tools/rebalance.py пересчитывает маршрут и покрытие; tools/tides.py сохраняет приливы. Карты экспортируются через tools/export-maps.html?day=1 (дни 1–8) и ?day=overview. Затем tools/build_pdf.py создаёт PDF, tools/verify.py проверяет покрытие, часы, дороги, катера, отдых и аэропорт.

PDF и статические карты содержат основной план. Личные перестановки еды в браузере не меняют PDF автоматически. Для нового календаря отдельное хранилище выбора, чтобы старые даты не перезаписывали новый план.
