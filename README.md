Без онлайн-подложки показывается сохранённая карта. «Поменять мой выбор» проверяет оба дня, часы, дороги, выезд с 09:00, сон, катера и аэропорт. Amok, Koral и Echo Beach заблокированы для простого обмена. Выбор хранится в браузере и экспортируется в JSON; PDF и статические карты содержат основной план.

## Данные и проверка

itinerary.json — расписание и геометрия дорог; registry.json — 68 заведений и 25 мест; restaurant-research.json — источники часов; coverage.csv — даты; latest-lists.json — текущий снимок списков; final-verification.json — выполненные проверки.

tools/rebalance.py пересобирает план; tools/export-maps.html отображает карты OpenFreeMap; tools/build_pdf.py собирает PDF; tools/verify.py проверяет даты, завтрак, выезд, покрытие, карты, дороги, сон, катера и аэропорт.

Локально: python -m http.server 8788 --bind 127.0.0.1 в папке проекта, открыть http://127.0.0.1:8788/ .
