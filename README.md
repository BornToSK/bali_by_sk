## Проверка и сборка

Генератор: `python tools/remaining.py` (или совместимый `tools/rebalance.py`). Текущие источники: `latest-lists.json`, `place-verification.json`, `meal-verification.json`, `food-ratings.json`, `catalog-additions.json`. Сначала обновить эти снимки через видимые карточки Maps, затем пересобрать данные, экспортировать карты через `tools/export-maps.html`, собрать `tools/build_pdf.py`, отрисовать все страницы и проверить `tools/verify.py`. Устаревшие инструменты подборки в истории Git не являются текущим маршрутом.

Локально: `python -m http.server 8788` из папки проекта, затем открыть http://localhost:8788/ .
